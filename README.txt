WHAT IS STRESSING THIS PLANT? — V2 REVIEW BUILD

Major changes:
- Persistent illustrated garden map replaces linear transition pages.
- Four distinct plant stops.
- After each completed stop, learners return to the same map.
- Boots animate from the completed stop to the next stop; the next plant becomes clickable only after arrival.
- Each stop shows the same five condition variables: daytime high, nighttime low, precipitation, soil moisture, recent event.
- Questions now use plausible competing explanations and require learners to weigh multiple clues.
- Conclusion refers only to plant observations + weather conditions (not unprovided site conditions).
- Ending now transitions toward management: what gardeners can do to help plants cope.
- Reduced-motion preferences disable the walking animation.

NOTE: Real-photo locations remain clearly labeled placeholders in this review build. The interaction/content should be reviewed before final photo selection and attribution.
